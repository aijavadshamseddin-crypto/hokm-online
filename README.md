# حکم آنلاین — Flutter starter v0.2

این بسته شامل رابط اولیه و موتور محلی چهار نفره حکم است. اتصال آنلاین هنوز پیاده‌سازی نشده است.

## پیش‌نیازها
- Flutter SDK و Dart 3.3 یا بالاتر
- Android Studio برای Android
- macOS و Xcode برای ساخت iOS

## اجرا
```bash
flutter pub get
flutter run
```

## اجرای تست‌ها
```bash
flutter test
```

## ساخت خروجی
Android:
```bash
flutter build apk --release
```

iOS (فقط روی macOS با Xcode):
```bash
flutter build ipa --release
```

## قابلیت‌های موتور
- پخش استاندارد پنج کارت اولیه، انتخاب حکم و سپس تکمیل دست هر نفر تا ۱۳ کارت
- تیم‌های روبه‌رو: صندلی‌های ۰ و ۲ در برابر ۱ و ۳
- انتخاب حکم فقط توسط حاکم
- گردش ساعت‌گرد نوبت‌ها
- الزام پیروی از خال شروع در صورت داشتن آن
- محاسبه برنده هر دست با اولویت حکم
- پایان دور با رسیدن تیمی به ۷ دست

## محدودیت
این پروژه هنوز بازی آنلاین یا نسخه آماده انتشار نیست. برای نسخه آنلاین، سرور باید مرجع قطعی بازی باشد و دست دیگر بازیکنان فقط در سرور محفوظ بماند.

تست‌ها آماده‌اند اما در محیط ساخت این بسته، Flutter SDK نصب نبود؛ بنابراین اجرای واقعی تست یا ساخت APK/IPA تأیید نشده است.
